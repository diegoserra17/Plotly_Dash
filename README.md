## Testes e Experimentos com Plotly Dash

Este repositório reúne pequenos testes, exemplos e experimentos práticos com o Plotly Dash, realizados durante meus estudos e desenvolvimento de aplicações interativas para análise e visualização de dados.

A proposta é explorar, de forma incremental, diferentes recursos do Dash e entender como seus principais componentes podem ser utilizados na construção de dashboards e aplicações web interativas com Python.

📊 Plotly
⚡ Dash
🌐 HTML
🎨 CSS
🔄 Callbacks
📋 DataTable
📊 Gráficos de barras (Bar)
📈 Visualização de dados

Entre os principais testes e funcionalidades abordados neste projeto estão:

🌐 HTML

Experimentação com componentes HTML disponibilizados pelo Dash, como:

html.Div
html.H1
html.Span
html.Br
html.B
html.I
html.Img
html.Hr

Os componentes podem ser combinados para estruturar a interface da aplicação. Um dos exemplos utiliza html.Div como estrutura principal e combina elementos de texto, imagem e um gráfico.

🎨 CSS

Testes relacionados à personalização visual das aplicações, explorando a integração entre componentes do Dash e estilos CSS.

🔄 Callback

Exemplos de callbacks do Dash, explorando a interação entre componentes e a atualização dinâmica de informações na aplicação.

📋 DataTable

Testes com tabelas interativas para apresentação e exploração de dados.

📊 Bar

Experimentação com gráficos de barras utilizando Plotly, incluindo a integração de figuras com componentes dcc.Graph.

🧩 Exemplos

Pequenos exemplos independentes foram utilizados para compreender a estrutura básica de uma aplicação Dash, desde a criação da aplicação até a definição do layout e execução do servidor.

📁 Estrutura do projeto

Os arquivos são organizados de acordo com cada conceito ou funcionalidade estudada, permitindo testar os recursos individualmente e acompanhar a evolução do aprendizado. Estão enumerados de 1 a 7.


🎯 Objetivo

Este projeto faz parte do um índice para aprendizado e experimentação com desenvolvimento em Python, visualização de dados e construção de aplicações interativas.

A ideia é compreender como diferentes componentes podem ser combinados para transformar dados em interfaces visuais, interativas e orientadas à análise.
